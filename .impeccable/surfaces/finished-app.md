# Authenticated command centre

- Scope: `src/finished-app.tsx` and `src/convos-app.css` only. The marketing landing page keeps its existing dark visual system.
- Mode: Operate.
- User job: Direct the CEO and specialist agents, inspect current runtime truth, review work and approvals, and finish production setup.
- Direction: A white native-messaging environment adapted from the supplied Convos references. Mobile uses a single-column agent inbox and focused thread. Desktop expands the same visual grammar into inbox, conversation, and operational-context panes.
- State language: Grayscale by default; orange identifies the CEO/agent control layer; iMessage blue is reserved for operator-authored outgoing messages. Unconfigured and local-only states remain explicit.
- Signature interaction: Select an agent as naturally as opening a conversation, then direct it from a familiar message composer while transport and authority remain visible.
- Constraints: No fabricated replies, live counts, jobs, skills, or integrations. Disabled media controls explain their missing provider. Existing Hermes bridge, setup, work, approval, knowledge, and settings behavior stays intact.
